# SmartAssistantBot

**SmartAssistantBot** — это многофункциональный Telegram-ассистент, объединяющий персональный тайм-менеджмент, игровую аналитику и мощь современных нейросетей. Проект разработан с акцентом на чистую архитектуру и масштабируемость.

---

## Ключевые возможности

### Смарт-Расписание
*   **Stateful Dialog:** Пошаговый мастер добавления занятий (выбор дня, времени, темы).
*   **Async Notifications:** Фоновый планировщик, который автоматически присылает уведомления за минуту до начала занятия.
*   **Persistence:** Надежное хранение всех данных в PostgreSQL.

### Dota 2 Analytics
*   Интеграция с **OpenDota API**.
*   Определение ранга в игре.
*   Привязка профиля по Account ID.

### AI Integration
*   Доступ к LLM-моделям через **OpenRouter API**.
*   Возможность ведения контекстного диалога с нейросетью прямо в мессенджере.

---

## Технический стек & Архитектура

Проект демонстрирует владение современными паттернами проектирования:

*   **Архитектурный паттерн Strategy:** Реализована система `UpdateDispatcher` и `InputMessageHandler`, позволяющая добавлять новые функции без изменения существующего кода (соблюдение принципа Open/Closed из SOLID).
*   **Finite State Machine (FSM):** Управление состояниями пользователя (`BotState`) для реализации сложных многоэтапных сценариев.
*   **Database Versioning:** Использование **Flyway** для надежной миграции схемы базы данных.
*   **Containerization:** Полная изоляция приложения и БД в **Docker-контейнерах** для упрощения деплоя.

---

## Схема работы системы

1. **Telegram API** ➔ Принимает сообщение.
2. **Spring Boot App** ➔ `UpdateDispatcher` определяет тип команды и текущее состояние пользователя.
3. **Business Logic** ➔ Обработка данных (расчет MMR, запрос к ИИ или работа с БД).
4. **PostgreSQL** ➔ Сохранение изменений.
5. **Scheduler** ➔ Каждую минуту проверяет базу на наличие активных уведомлений.

## Запуск

### Требования
*   Docker & Docker Compose
*   Maven
*   Telegram Bot Token (от @BotFather)

### Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ваш_логин/assistant-bot.git
   cd assistant-bot
   ```
2. **Настройте переменные окружения:**
   ```bash
   Добавьте в переменное окружения BOT_NAME, BOT_TOKEN, данные БД
   ```
3. **Соберите и запустите проект:**
   ```bash
    mvn clean package -DskipTests
    docker-compose up --build
   ```
